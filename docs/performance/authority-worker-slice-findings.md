# Isolated authority-worker slice: evidence, not a release

## State at 2026-10-24 07:30 UTC

The normal game entry is unchanged by this experiment. Independent performance-branch commit `24fb022af77cb8b9a6fcd398cd247a2515bb8028`, Actions run `40073889468`, reached actual browser execution and failed the performance gates. This is not a replacement game or a completed performance fix.

The original suite passed 599 tests with one existing skip; 40 new isolated tests passed in that commit. A real Node Worker was compared against a separately executed synchronous authority: three different building-surface nova detonations, identical original power and trigger rules, exact raw snapshot hashes after each shot, natural settlement at 663 fixed steps, native world peak one and zero after disposal. The fake-clock comparison proves state equivalence, not realtime throughput. Worker damage calls still cost 662 / 526 / 480 ms natively.

## First real browser result

The city used an actual module Worker and three different worker-confirmed building hosts. Damage reached the authority after 1219 / 730 / 684 ms. The largest measured main-thread long task was 884 ms. Two trusted probe-button samples were about 4.9 ms; this limited local response does not certify general responsiveness.

The requested two-second firing cadence was not achieved: observed intervals were 9.1 and 16.7 seconds. The first pressure window included a 2.77-second screenshot, camera dragging, sequential input/ack handling and repeated aiming work. Those are measurement interference, not a valid engine throughput estimate. They do not explain away the independently measured authority calls exceeding 250 ms.

The courtyard scenario stopped at an overly indirect camera-projection assertion. The city completed observations, saved the settled scene and ran the end/dispose route, but failed component gates. Actual images show three large craters and 43.5% building damage, not a performance pass.

## Bounded correction before one final measurement

- Keep exact weapon/physics semantics and all thresholds.
- Preverify three separated actual visible surfaces before pressure; use trusted canvas and button actions on absolute two-second deadlines, without waiting for each damage acknowledgement or taking screenshots during pressure.
- Reconcile accepted host IDs and real damage positions afterward. Failed or late commands remain failures, never silently retargeted during the window.
- Camera proof waits for an actual rendered camera transform change.
- Retain worker-side maximum eligible simulation debt, not only sparse samples.
- Use a separately bounded/coalesced visibility-clock lane so a saturated gameplay command queue cannot lose the last visibility state.
- Distinguish CPU geometry installation, ray picking, effects, controls and WebGL render submission. WebGL submission timing is not a GPU timer and buffer-wrapper installation is not GPU-upload completion.

## Stop and redirect criterion

If the corrected measurement still exceeds 250 ms authority damage latency, or debt fails to recover, do not integrate this slice as the finished solution. Worker placement isolates scheduling but does not reduce the number of authoritative cells edited. The next proposal must change regional storage/edit and support work: exact full-region destruction only where bounds and material/HP prove equivalence, fine evaluation at blast boundaries, shared regional ledger accounting, incremental coarse support and dirty collision/mesh work. It must preserve IDs, research and current instantaneous damage semantics unless a separate gameplay timing change is explicitly approved.

The prior instrumented native profile identifies roughly 99,000 writable/changed-cell operations on the first central blast, plus support splitting, collider repacking and immutable-view/ledger work. Instrumented nested timers overlap and inspector overhead is significant; these are candidate work classes, not additive wall-time attribution.

Four-times unrelated distant-map full-physics locality, per-affected-chunk freshness, exact queued-body age, Android performance and normal-game integration remain unverified. No claim that this scales to planets or galaxies follows from this slice.
