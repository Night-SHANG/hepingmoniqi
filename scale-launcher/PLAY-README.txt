核平：规模优先城市验证片

这是独立实验，不是主游戏升级包。不要覆盖原游戏文件夹。

Windows：解压到新文件夹，双击 START-WINDOWS.bat。需要 Python 3，启动后自动打开浏览器。保持命令窗口开启。
固定地址为 http://127.0.0.1:7770/ ，与原游戏7769隔离。若7770被其他程序占用，请先关闭占用窗口，不会切随机端口。

怎么测试
1. 点击“进入测试场景”。首次初始化仍可能需要数秒，云端软件渲染实测约8.6秒到完整画面，尚未完成启动优化。
2. 鼠标拖动环绕，滚轮缩放。点击可见建筑或地面选落点。
3. “放置核爆弹”后点“遥控引爆”。可以放多个，也可用“发射核爆弹”测试实体弹体。
4. 下拉选择火箭弹可做小范围局部破坏；界面为实验控制面板，不是最终UI。
5. 暂停/恢复、重建现场、静止后暂存和恢复可用于检查。暂存只在当前页面会话内，刷新或关闭后丢失。
6. “结束等待”会等重要物理活动完成；烟尘尾部不强制等待。可释放场景后重新进入。

验证边界
- 规模优先：远处按结构区域计算，局部小爆破有精细孔洞，重要残骸保留真实碰撞；不承诺每格都按旧版独立承重。
- 画面中的研究数值是原始破坏统计，不是主游戏研究余额。本片不读取或写入原游戏存档。
- 这里只验证城市/庭院、两种工具和物理链路，不包含主游戏配装、成长和完整音效接入。
- 三次城市核爆已真实运行并自然落稳、保存/恢复，但软件渲染的帧响应仍未通过全部性能门槛；不能称性能已经全面修复。Android和真实手机未测试。
- 建筑和地形变化、残骸是实时状态，不是预录动画。部分超出有限地图的残骸会被明确退场。

请重点反馈：放置后引爆是否立即出现真实破坏；连续三次后拖动/按钮是否仍灵敏；小坑和后续弹体碰撞是否合理。
