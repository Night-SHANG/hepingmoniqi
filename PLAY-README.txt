核平模拟器 v0.4｜有限弹药破坏实验

完整解压后，Windows 安装 Python 3 并双击 START-WINDOWS.bat；macOS/Linux 执行 python3 serve.py。自动打开浏览器，保持服务窗口开启。不能直接双击 index.html。

主模式每轮共6枚。少量建筑破坏也获研究，重试补满弹药并保留研究。40研究解锁火箭，90解锁遥控包，120解锁仓库。无需达到70%或100%才能结束。

拖动旋转、滚轮缩放、点击瞄准。投放可选快捷逐发、轨迹预览确认、直接放置。发射可选自动或统一遥控；放置的工具等待统一引爆。轨迹预览不扣弹，确认后扣弹。手动点击结束本轮，剩余遥控弹会引爆，等飞行与爆炸效果结束后才显示结果。

自由模式任选建筑、无限弹药及放置数量，但武器需在主模式解锁；自由破坏不增加研究。暂停/慢动作影响模拟，重建可取消当前弹体。

这是浏览器试玩包，不是Android APK；地面、水面与远景不可破坏，旧版研究存档会保留。
