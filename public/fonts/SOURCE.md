# Courtyard Sans subset

Derived from Noto Sans CJK SC Regular, supplied by the fonts-noto-cjk package. Only characters used by the game plus printable ASCII are retained. Renamed Courtyard Sans and redistributed under SIL Open Font License 1.1.

Upstream: https://github.com/notofonts/noto-cjk

The isolated structural laboratory additionally uses `structural-sans.woff`, a separately renamed Structural Sans subset of the same Noto Sans CJK SC Regular source and OFL license. It contains the laboratory controls/status characters and printable ASCII; no external font service is used.
