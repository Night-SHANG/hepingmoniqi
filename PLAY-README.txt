核平模拟器 v0.9｜真实地形与废墟开发版

【启动】
完整解压后，Windows 双击 START-WINDOWS.bat（需要 Python 3）；macOS / Linux 运行 python3 serve.py。浏览器自动打开 http://127.0.0.1:7769/，游玩时保持服务窗口运行。不要直接双击 index.html，需要支持 WebGL2 的浏览器。
端口固定，不会自动换端口；已有服务须通过游戏身份校验才能复用。切换新版前先关闭旧游戏服务窗口，否则可能继续打开旧版。尚未做真实 Windows 设备验收。

【内容与解锁】
0 研究：木屋庭院、手榴弹、6 格容量。
40：火箭弹。90：遥控爆破包。120：双跨仓库、8 格容量。
240：高架连廊、回声震荡器。420：叠层塔楼、分裂球、10 格容量。
620：悬臂观景台、穿行球。900：九栋街区、街区冲击弹。
1400：六区城市、城市核爆弹。最高仍为 10 格，12 格未开放。

九栋街区有九栋独立建筑；六区城市有六个街区、每区六栋，共 36 栋。采用与早期小屋一致的暖色自建模块。地图内建筑、八层有限地面、道路、树木与桥梁均可破坏，失支撑大构件真实落下、撞击和留作废墟；细尘屑是表现。天空及地图外远景是背景，不是无限地下世界。
街区冲击弹基准半径 16，城市核爆弹基准半径 48，均指 100% 威力下的虚构游戏单位；可跨栋或跨街区，不是现实武器模拟，也不是自动清空城市。

【准备与配装】
左侧纵向场景列表、中间实时三维预览、右侧配装。两侧列表分别内部滚动，容量与开始按钮留在列表外。
主模式、自由模式每轮均选 1 至 3 种已解锁工具，限制种类，不是枚数。主模式按数量占格，可以不装满；减至 0 后可换入其他种类。
每枚占格：手榴弹 1；火箭弹、遥控爆破包 2；回声震荡器、分裂球、穿行球、街区冲击弹 3；城市核爆弹 5。
研究永久累计、不消费，沿用原全局规则：整张地图的建筑生命损失每轮最多产生 200 研究，不按栋数倍增；非建筑道具不计研究。旧研究、历史奖励与解锁保留，不改成章节独立账本。
新解锁与扩容只在下一轮配装生效，不给当前回合补弹。自由模式可选全部七图，所选工具无限使用、不增加研究，但工具解锁仍继承主模式。

【操作】
点击建筑或可选地面瞄准，拖动旋转，滚轮缩放；空格或主操作按钮发射 / 放置，数字 1 至 3 切换本轮工具。没有轨迹预览或确认步骤。
左侧只显示本轮工具，可收起 / 展开；折叠不暂停或改变配装、库存、瞄准点。右下操作区独立保留，耗尽工具仍显示但不能使用。
手榴弹自动发射后 3 秒引爆；火箭弹、街区冲击弹、城市核爆弹自动发射后碰撞引爆。可发射工具可改为遥控；遥控爆破包、回声震荡器只能放置，所有放置都需遥控触发。
回声触发后在 0、0.65、1.30 秒产生三次伤害；分裂球生成三个真实物理子球。穿行球沿真实路径最多触发三个不同体素接触点，自动发射即激活；遥控发射须在 12 秒模拟寿命内激活，触地或越界也会提前结束，不补算已飞过的接触点。表面放置后向结构内部释放，实际土层表面放置同样沿命中面法线向内释放。
弹体与脉冲计时随模拟暂停、慢速变化。已开始的短音与尾响使用音频时间，不因暂停重新触发；设置静音、切后台或重建会停止声音。

【结束、重试与存档】
弹药用完不会自动结算、暂停或重建。主动“结束本轮”会等待弹体、连续脉冲、关键坍塌与核心视觉效果（不等纯烟尾）；声音尾响不阻塞结算。结算后可“查看现场”。
“再次挑战”重建同一地图、沿用原确切配装；要使用新工具或调整数量，请选“更换场景 / 配置”。
当前为 schema 9 稀疏现场，优先使用浏览器 IndexedDB。旧版存储键不覆盖，校验后保留研究、解锁和已用库存记录。因结构 / 地形系统改变，需要明确重新配装开始新轮，不暗中补弹。恢复现场不会重播已发生爆炸，正在飞行的弹体不跨重载恢复。
存档属于当前浏览器与完整服务地址，不是云存档。旧随机端口存档留在原地址，不会自动迁移到 7769，也不会被新版清除。更换浏览器、地址或清除站点数据会影响读取。

【验证与范围】
结构实验已通过实际浏览器验证；正式游戏和新烟火的本轮验收仍在进行，以随包发布说明为准。城市内存成本较高，未通过真实 Android 性能验收，推荐先在桌面浏览器体验。
八种工具使用不同主引爆采样，城市音效有独立主体与尾层，最多六个声音声部。已做自动化检查，未做主观听感、真实手机扬声器或长期设备性能验收。
目前没有星球、黑洞、宇宙 / 太空玩法、Android APK 或原生安装包。重复旧地图仍可获得研究，成长节奏与后期平衡尚待实玩。
