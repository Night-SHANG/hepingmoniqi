核平模拟器 v0.3｜庭院与仓库

完整解压后，Windows 安装 Python 3 并双击 START-WINDOWS.bat；macOS/Linux 执行 python3 serve.py。自动打开浏览器，保持服务窗口开启。不能直接双击 index.html。

拖动旋转，滚轮缩放，点击物体瞄准。1 手榴弹：抛出后 3 秒爆炸。2 火箭弹：40 研究解锁，碰撞爆炸。3 遥控包：90 研究解锁，贴到物体后按遥控引爆。
拆除目标建筑的 70% 即完成，不用清理树木围栏。庭院完成解锁仓库；可重试或进入独立自由模式。暂停与慢动作同时影响物理和倒计时。

这是浏览器试玩包，不是 Android APK；地面、水面与远景不可破坏。
