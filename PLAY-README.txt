核平模拟器 · 小屋试验场

Windows：先完整解压，再双击 START-WINDOWS.bat。
启动器会使用已安装的 Python 3 启动仅本机访问的服务器，并自动打开默认浏览器。游玩时请保留命令窗口。
如果未安装 Python 3，请从 https://www.python.org/downloads/windows/ 安装后重试。
macOS / Linux：在解压目录运行 python3 serve.py。
不要直接双击 index.html，三维模块需通过本机 HTTP 服务加载。

拖动：旋转镜头。滚轮：缩放。点击小屋：选落点。空格或发射按钮：发射。
数字 1–3：切换已解锁工具。重建：恢复小屋，不删除成长研究。
设置：沙盒、静音、慢动作观察。浏览器本地保存，换浏览器或清理网站数据不会保留进度。

这是 E0 小屋首个可玩候选，不含完整八章内容。
当前通过代码构建和领域测试；真实浏览器截图、设备性能和听感尚待验证。
